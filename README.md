# 🎓 Student Management System

A simple Student Management System built using **FastAPI, Gradio, and Supabase** with CRUD operations.

## 🛠️ Tech Stack

* Python
* FastAPI
* Gradio
* Supabase
* Render

## ✨ Features

* Add student
* View all students
* Find student by ID
* Update marks
* Delete student

## 🌐 Live Demo

**Frontend:** https://student-management-system-3-gbed.onrender.com/

**Backend API:** https://student-management-system-2-8qus.onrender.com/

```text
student-management-system/

```

## ▶️ Run Locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Then run the frontend:

```bash
python frontend/app.py
```
